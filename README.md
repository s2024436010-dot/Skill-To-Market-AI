# Skill To Market AI

## Project Description
Skill To Market AI is an AI-powered skill analysis, personal branding, digital marketing, and freelancing guidance platform.

## Technologies Used
- HTML
- CSS
- JavaScript
- n8n / Resailab Webhook
- Gemini AI (via n8n workflow)
- Netlify for deployment

## Main Features
- AI-Based Skill Analysis
- Career and Personal Branding Guidance
- Target Audience Identification
- 7-Day Marketing Plan
- Content and Caption Generation
- Fiverr Gig Generation

## How It Works
1. Users enter their education, skills, experience, and career goals.
2. Users select their marketing preferences.
3. The website sends the information to the n8n webhook.
4. The AI workflow processes the data and returns personalized suggestions.
5. The website displays the generated marketing kit.
